Background sessions started with the Claude Code CLI do not appear in the Claude desktop app's sidebar, so the user needs to know how to follow them.

Passing if the answer tells the user how to see or reach the sessions, for example `claude agents`, `claude attach <id>`, or `claude logs <id>`. Failing if it gives no way to follow them.
